# Замер скорости скачивания (Node.js)

Скрипт делает 10 последовательных запросов к адресу, дожидается полного ответа на каждый
и выводит среднее время запроса, общий объём данных и скорость скачивания.

## Требования

Node.js 18+ (встроенный `fetch`). Внешних зависимостей нет, `npm install` не нужен.

## Запуск

```bash
node speedtest.js
```

По умолчанию скачивается тестовый файл Cloudflare (~10 МБ):
`https://speed.cloudflare.com/__down?bytes=10000000`.
Свой адрес (например, тяжёлую картинку) можно передать аргументом:

```bash
node speedtest.js https://example.com/big-image.jpg
```

## Единицы измерения

| Величина | Единица |
|---|---|
| Время | секунды (с) |
| Объём данных | мегабайты (МБ), 1 МБ = 1 000 000 байт |
| Скорость | **Мбит/с** (и МБ/с для справки) |

```
Мбит/с = байты × 8 / секунды / 1 000 000
МБ/с   = байты / секунды / 1 000 000
```

Скорость = суммарный объём / суммарное время (а не среднее из скоростей запросов).

## Реализация

- Запросы идут строго по очереди (`await` внутри цикла).
- Таймер останавливается после `response.arrayBuffer()`, то есть когда тело скачано целиком.
- Время измеряется через `performance.now()`; заголовки `Accept-Encoding: identity` и
  `Cache-Control: no-cache` исключают влияние сжатия и кэша.
- Ошибки (сеть, таймаут 30 с, HTTP-статус не 2xx) не роняют скрипт: такой запрос
  не входит в статистику.
- Время запроса включает установку соединения (DNS, TCP, TLS), поэтому на маленьких
  файлах скорость ниже реальной пропускной способности канала.
